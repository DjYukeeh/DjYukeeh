# Site da DJ Yukeeh

Site estático responsivo feito com HTML, CSS e JavaScript, pronto para publicação no GitHub Pages.

## Antes de publicar

1. Abra `index.html`.
2. Procure `SEUEMAIL@EXEMPLO.COM` e substitua pelo e-mail profissional correto.
3. Substitua os links de exemplo do YouTube/TikTok pelos seus perfis e links de músicas.
4. Atualize os títulos e descrições das músicas para combinar com os lançamentos que quer destacar.
5. Se quiser usar suas capas reais, substitua os cards abstratos no HTML por imagens suas.

## Publicar com GitHub Pages

1. Entre em https://github.com e crie uma conta, caso ainda não tenha.
2. Clique em **New repository**.
3. Dê o nome `djyukeeh.github.io` se o seu nome de usuário for `djyukeeh`. Se for outro, use `SEUUSUARIO.github.io` para um site de usuário, ou qualquer nome para um projeto.
4. Deixe o repositório **Public** e crie-o.
5. Envie os arquivos deste pacote para a raiz do repositório: `index.html`, `styles.css`, `script.js` e `README.md`.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**.
8. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
9. Aguarde a publicação e abra o endereço indicado na tela do GitHub Pages.

## Observações

- GitHub Pages hospeda sites estáticos. Este projeto não precisa de servidor nem banco de dados.
- O endereço final depende do seu nome de usuário e do nome do repositório.
- Google Fonts precisa de conexão com a internet; se não carregar, o site usa fontes alternativas.
- Os links de exemplo precisam ser atualizados antes de divulgar o site.
